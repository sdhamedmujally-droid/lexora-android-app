# 📱 مشروع تطبيق Lexora English Lab للأندرويد عبر Capacitor و GitHub Actions

هذا المشروع مهيأ بالكامل لتحويل تطبيق **Lexora** إلى تطبيق أندرويد بصيغة **APK** قابل للتنزيل والتثبيت على الهواتف مباشرة باستخدام أداة **Capacitor** ونظام الأتمتة السحابي **GitHub Actions**، دون الحاجة لتثبيت أي برامج أو بيئة تطوير على حاسوبك.

---

## 🚀 طريقة الاستخدام في خطوات بسيطة (عبر متصفحك أو هاتف):

### 1. إنشاء مستودع جديد على GitHub (New Repository):
1. افتح موقع [GitHub](https://github.com) وسجّل دخولك.
2. اضغط على زر **New** لإنشاء مستودع جديد (Repository).
3. اختر اسماً للمستودع (مثلاً: `lexora-android-app`).
4. اجعل المستودع **Public** أو **Private** (كلاهما يعمل).
5. اضغط على **Create repository**.

### 2. رفع ملفات المشروع إلى المستودع:
- اضغط على **uploading an existing file**.
- قم بسحب وإسقاط محتويات هذا المجلد (أو فك ضغط ملف `lexora-capacitor-ready.zip` ورفع كافة محتوياته بما فيها مجلد `.github` ومجلد `www` وملفات `package.json` و `capacitor.config.json`).
- اضغط **Commit changes**.

### 3. بناء ملف الـ APK تلقائياً:
1. بمجرد رفع الملفات، توجه إلى تبويب **Actions** في أعلى صفحة المستودع على GitHub.
2. ستجد إجراء يعمل تلقائياً باسم: **Build Lexora Android APK**.
3. انتظر دقيقتين إلى 3 دقائق حتى تظهر علامة الصح الخضراء ✅.

### 4. تنزيل التطبيق (APK) على هاتفك:
لديك طريقتان سهلتان لتنزيل التطبيق:

* **الطريقة الأولى (الأسهل مباشرة): قسم الـ Releases:**
  - في الصفحة الرئيسية للمستودع، توجه إلى قسم **Releases** الموجود في القائمة الجانبية يميناً.
  - ستجد إصداراً جديداً (مثال: `Lexora English Lab v1.0.1`).
  - اضغط مباشرة على ملف `Lexora-English-Lab.apk` وسيبدأ التحميل فوراً إلى هاتفك!

* **الطريقة الثانية: قسم الـ Actions:**
  - ادخل على تبويب **Actions** واضغط على آخر تشغيل ناجح.
  - انزل لأسفل الصفحة عند قسم **Artifacts**.
  - اضغط على `Lexora-English-Lab-APK` لتحميل الملف.

---

## ⚙️ بنية المشروع:
- `www/`: يضم كافة ملفات الواجهة والبيانات والمكتبات الخاصة بتطبيق Lexora (بما في ذلك 5000 كلمة، والقصص والمحادثات).
- `capacitor.config.json`: ملف إعدادات Capacitor لتوليد تطبيق الأندرويد.
- `package.json`: الحزم والاعتمادات اللازمة لـ Capacitor 6 و Android.
- `.github/workflows/build-apk.yml`: سير العمل التلقائي الذي يقوم ببناء وتوليد ملف الـ APK وتخصيص أيقونة التطبيق تلقائياً من ملف `icon.svg`.
